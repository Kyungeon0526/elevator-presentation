# 엘리베이터 스트리밍 시그널링 서버

WebSocket signaling 서버용 엘리베이터 실시간 스트리밍 시스템.

## 배포 방법

### 1. Render에 배포 (추천)

```bash
# 1. Render 계정 생성
# 2. 새 Web Service 생성
# 3. GitHub 저장소 연결
# 4. Build Command: `npm install && node server.js`
# 5. Start Command: `node server.js`
# 6. 포트: 3001
```

### 2. 로컬 테스트

```bash
# 서버 시작
npm install
node server.js
```

## 서버 포트

- **WebSocket**: `3001`
- **HTTP**: `3001` (헬스체크용)

## API 엔드포인트

### 상태 확인
- `GET /health` - 서버 상태 확인

### 방 관리
- `GET /room/{roomId}` - 방 정보 확인

## 사용 방법

1. 발표용 노트북에서 사이트 접속
2. "휴대폰 촬영" 탭 선택
3. 방 이름 입력 (예: elevator-demo-2024-08-27)
4. "송출 시작" 클릭
5. 휴대폰에서 같은 방 이름으로 접속
6. 실시간 연결 완료

## 연결 순서

### 발표용 노트북 (송출자)
1. 방 이름 입력
2. "송출 시작" 클릭
3. 카메라/마이크 권한 요청
4. Offer 생성 및 서버 전송
5. 기다림

### 휴대폰 (수신자)
1. 같은 웹사이트 접속
2. "휴대폰 촬영" 탭 선택
3. 같은 방 이름 입력
4. 접속 요청
5. 서버에서 Offer 수신
6. Answer 생성 및 전송
7. 실시간 연결 완료

## 중요 사항

- 방 이름은 영어로 입력 (예: `elevator-demo-2024-08-27`)
- 같은 방 이름으로만 연결 가능
- 호스트가 나가면 자동으로 방 종료
- 10분 미활동 방 자동 정리
- STUN 서버 사용으로 NAT 통과
- TURN 서버 없음 (필요시 추가 가능)

## 서버 관리

### 방 퇴장
- 호스트가 나가면 자동 종료
- 시청자가 모두 나가면 유지
- 1시간 이상 비활동 방 자동 삭제

### 연결 안정성
- 연결 끊길 시 자동 재연결
- 재연결 3회 시도 후 종료
- 연결 상태 실시간 표시

## 트러블슈팅

- **연결 끊김**: 자동 재연결 시도
- **방 삭제**: 호스트 퇴장 or 10분 미활동
- **서버 재시작**: 모든 연결 초기화
- **클라이언트 오류**: 연결 종료 및 에러 메시지

## 실시간 통계

- 활성 방 수: `/health` 엔드포인트 확인
- 현재 접속자 수: 각 방별 시청자 수 추적
- 연결 시간: 방 생성/종료 시간 기록
