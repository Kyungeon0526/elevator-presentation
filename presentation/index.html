왜 이 프로젝트를 하게 됐는지

❌ 문제 상황

  • 엘리베이터를 이용할 때 닫힘 버튼을 직접 눌러야 함
  • 짐을 들고 있거나 버튼에서 멀리 서 있으면 불편
  • 엘리베이터 현재 층을 실시간으로 확인하기 어려움

✅ 해결 목표

  • 닫힘 버튼을 자동으로 누르는 시스템 구현
  • 실시간 엘리베이터 층수 모니터링
  • 사용자 편의성 향상

프로젝트 개요

🎯 프로젝트명

스마트 엘리베이터 자동화 시스템

📋 개요

ESP32-S3 Sense 카메라를 사용하여 엘리베이터 상황을 감지하고 제어하는 시스템

🎯 목표

  • 닫힘 버튼 자동 누름으로 사용자 불편 해소
  • 실시간 층수 모니터링으로 정보 접근성 향상
  • 실효성 데이터 수집을 통한 성과 검증

초음파 센서 (HC-SR04)

기능 1 - 닫힘 버튼 자동 누름

🔄 작동 원리

  1. 카메라로 상황 학습
  2. 닫힘 버튼 누르는 상황 판단
  3. 서브모터 움직여 닫힘 버튼 누름

✨ 특징

  • ESP32-S3 Sense 1대로 통합
  • 내장 카메라 사용
  • 서브모터로 정확한 버튼 누름

기능 2 - 엘리베이터 층수 디텍팅

📐 방식

7-segment 숫자 인식 (전통적 비전)

⚙️ ESP32 기능

  • 카메라 캡처 (160x120 그레이스케일)
  • 이미지 전처리 (다운샘플링, 이진화)
  • ROI 추출 (숫자 영역 자동 감지)
  • 7-segment 세그먼트 분석
  • 패턴 매칭으로 0-9 숫자 인식
  • HTTP API 제공

🔌 API 엔드포인트

GET /api/status - 층수 데이터 (JSON)
GET /api/segments - 세그먼트 분석 결과 (JSON)
GET /capture - 카메라 이미지 (JPEG)

웹사이트 기능

🖥️ 메인 페이지 (index.html)

  • 실시간 층수 표시
  • 엘리베이터 방향 (▲ 상행, ▼ 하행, ■ 정지)
  • 시간대별 이용량 차트
  • 총 이용량 통계
  • 2초 주기 실시간 업데이트

🔧 디버깅 페이지 (debug.html)

  • 실시간 카메라 이미지 표시
  • 숫자 인식 결과 및 신뢰도
  • 7-segment 세그먼트 시각화
  • 인식 로그 및 통계
  • 업데이트 주기 조절 (100ms ~ 5000ms)

기능 3 - 초음파 센서 기반 문 상태 감지

📡 센서

HC-SR04 초음파

🎯 목적

총 닫힌 횟수 계산 (실효성 데이터)

⚙️ 기능

  • 문 열림/닫힘 여부 판단
  • 총 닫힌 횟수 계산

라이브 시연

📹

실시간 층수 모니터링 연동

실제 ESP32가 연결되면 실시간으로 층수가 표시됩니다

시연 내용

  • 실시간 층수 모니터링 연동
  • 웹캠 영상 표시
  • 숫자 인식 결과 실시간 확인
