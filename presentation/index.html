문제 정의

🏫 문제 발견

⏱️ 불필요한 시간 낭비

승객이 모두 내린 뒤에도 문이 약 13초 이상 열린 상태로 유지되는 것이 반복되면 비효율적입니다.

📦 불편한 사용 환경

특정 상황에서 사용자가 직접 닫힘 버튼을 누르는 것이 불편합니다.

  • 🎒 양손에 짐을 들고 탑승한 경우
  • 🤲 손이 자유롭지 않은 경우

프로젝트 개요

🎯 프로젝트명

스마트 엘리베이터 자동화 시스템

📋 개요

ESP32-S3 Sense 카메라를 사용하여 엘리베이터 상황을 감지하고 제어하는 시스템

🎯 목표

  • 닫힘 버튼 자동 누름으로 사용자 불편 해소
  • 실시간 층수 모니터링으로 정보 접근성 향상
  • 실효성 데이터 수집을 통한 성과 검증

기능 1 - 닫힘 버튼 자동 누름

🔄 작동 원리

  1. 카메라로 상황 학습
  2. 닫힘 버튼 누르는 상황 판단
  3. 서브모터 움직여 닫힘 버튼 누름

✨ 특징

  • ESP32-S3 Sense 1대로 통합
  • 내장 카메라 사용
  • 서브모터로 정확한 버튼 누름

기능 2 - 엘리베이터 층수 디텍팅

📐 방식

7-segment 숫자 인식 (전통적 비전)

⚙️ ESP32 기능

  • 카메라 캡처 (160x120 그레이스케일)
  • 이미지 전처리 (다운샘플링, 이진화)
  • ROI 추출 (숫자 영역 자동 감지)
  • 7-segment 세그먼트 분석
  • 패턴 매칭으로 0-9 숫자 인식
  • HTTP API 제공

🔌 API 엔드포인트

GET /api/status - 층수 데이터 (JSON)
GET /api/segments - 세그먼트 분석 결과 (JSON)
GET /capture - 카메라 이미지 (JPEG)

웹사이트 기능

🌐 실시간 웹사이트

※ 친구가 만든 웹사이트 URL을 아래 스크립트에 입력하면 자동으로 표시됩니다

🔗

웹사이트가 준비 중입니다

나중에 URL을 입력하면 실제 웹사이트가 표시됩니다

🖥️ 메인 페이지 (index.html)

  • 실시간 층수 표시
  • 엘리베이터 방향 (▲ 상행, ▼ 하행, ■ 정지)
  • 시간대별 이용량 차트
  • 총 이용량 통계
  • 2초 주기 실시간 업데이트

🔧 디버깅 페이지 (debug.html)

  • 실시간 카메라 이미지 표시
  • 숫자 인식 결과 및 신뢰도
  • 7-segment 세그먼트 시각화
  • 인식 로그 및 통계
  • 업데이트 주기 조절 (100ms ~ 5000ms)

기능 3 - 초음파 센서 기반 문 상태 감지
