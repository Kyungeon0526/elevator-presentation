📱

현장 무선 조정 시스템

카메라(판단부)와 서보모터(실행부)를 분리 설치하고 ESP-NOW로 무선 연동합니다. 엘리베이터 배선을 건드리지 않고도 판단 결과를 실시간으로 전달합니다.

⚠️

카메라 각도 오작동 해결

사람이 보이거나 판단이 애매하면 절대 버튼을 누르지 않습니다. 오작동으로 인한 안전사고보다 "조금 늦게 닫히는 것"을 택하는 보수적 설계입니다.

✨

기존 시스템 비침해

엘리베이터 제어반과 배선을 전혀 개조하지 않습니다. 승객이 직접 누르던 버튼을 서보모터가 물리적으로 대신 누를 뿐이라 탈부착만으로 설치·철거가 가능합니다.

🔴 문제점 — 카메라 각도 차이로 AI 판단이 흔들렸다

• 학습 데이터 촬영 각도와 실제 설치 각도가 달랐음
• 같은 상황도 카메라 각도에 따라 다르게 보임
• 카메라 높이·기울기 차이로 사람과 문의 위치가 화면에서 달라짐
• 이로 인해 AI 판단 결과가 흔들릴 수 있었음

🟢 해결

• 카메라 각도를 조금씩 바꿔가며 데이터 추가 수집
• AP 화면에서 현재 카메라 구도를 직접 확인
• 학습 당시 화면을 반투명 가이드로 겹쳐 실제 설치 각도 보정

📺 실시간 웹사이트 미리보기

🔴 문제 1 — 기압센서의 불안정한 층수 판단

• 초기에는 층마다 기압이 다르다는 점을 이용해 BMP 기압센서로 현재 층을 추정하려 했다
• 하지만 층간 기압 차이가 작고, 문 개폐·환기·사람 이동·날씨 등에 따라 기압값이 변해
• 같은 층에서도 측정값이 흔들리는 문제가 발생했다

🟢 해결

• 기압으로 층수를 간접적으로 추정하는 방식을 포기하고
• 엘리베이터에 이미 정확하게 표시되고 있는 층수 표시기를 카메라로 직접 인식하는 방식으로 변경했다

🔴 문제 2 — 정면 설치의 사용자 불편

• 처음에는 7세그먼트의 각 점등 상태를 읽는 디코딩 방식을 검토했지만
• 정확한 인식을 위해서는 카메라가 층수 표시기를 정면에서 바라봐야 했다
• 이 경우 카메라가 층수 화면을 가려 승객의 시야를 방해하고 심미성이 떨어지는 문제가 있었다

🟢 해결

• 사용자에게 방해되지 않도록 카메라를 층수 표시기 위쪽에 설치해 위에서 아래로 촬영하도록 변경했다
• 이 때문에 숫자가 왜곡되어 보였지만, 실제 설치 위치에서 보이는 각 층의 왜곡된 숫자를 직접 수집해 기준 이미지로 등록하고
• Template Matching 방식으로 층수를 인식했다

문 개방시간 데이터 확보

✨

Before/After 정량 비교

장치 적용 전(A)과 적용 후(B)를 같은 장소·같은 조건에서 비교해 개방시간 감소를 수치로 보여줍니다. 감이 아니라 통계로 말합니다.

🔴 문제점 1 — ToF 센서 배송 지연

• 초기에는 ToF 센서를 이용해 문의 거리 변화를 측정할 계획이었지만
• 센서 배송이 예상보다 늦어져 실험 및 데이터 수집 일정이 지연될 상황이 발생했다

🟢 해결

• 필요한 것은 특정 ToF 센서가 아니라 '문이 열리고 닫힐 때 발생하는 거리 변화를 측정하는 기능'이라고 다시 정의했다
• 이에 기존에 보유하고 있던 초음파센서와 ESP32C6를 연결해 동일한 목적의 계측 시스템을 구현했다
